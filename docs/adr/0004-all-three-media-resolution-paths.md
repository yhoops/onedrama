# 取流三级全搬，包含第三方备用源

红果取流是 App 签名 API → 网页 `/player/{series}/{vid}` → 第三方 `djapi.999888456.xyz`，后两级经常返回明文流，这正好是 CENC 密钥注入失败时的兜底，所以三级都搬。代价是第三方域名能看到你请求了哪一集，这条路只在这个 APK 不外发的前提下成立。

## Considered Options

- **只走 App + 网页**：少一个不可控域名，但网页一路挂掉就只剩 App。
- **只走 App 签名 API**：Dart 侧工作量最小，但协议一改整个 App 停，且没有明文兜底。

## Consequences

分发范围因此被限制为私下传包。若哪天要公开发 APK，这一条和签名进包要一起重做（签名得挪到自建后端）。

> **已被 [ADR-0014](0014-publish-apk-publicly.md) 覆盖**（2026-09-24）：仓库转为公开，并在
> GitHub Releases 上公开发布 APK。上面这两句不再成立，风险已由用户知情后接受。本 ADR 关于
> 「三级取流都搬」的技术决定本身仍然有效。
